프로페셔널 메뉴

보고, 묶고, 옮기고, 남기기

프로페셔널 보기의 메뉴 순서대로 소개합니다. 사진을 고르고 분류하는 일은 Mac 안의 AI(Apple Vision 등)가 합니다.

01 · 🗂 업무 사진첩

모든 사진을 날짜순으로, 종류별로 걸러 보기

  • 사진첩 폴더의 모든 사진·동영상을 날짜순으로 한 화면에 — 주말이 아닌 날도 빠짐없이.
  • 종류로 바로 거르기:
    사진동영상문서·영수증스크린샷사람동물
  • PDF·Word로 공유하고, 필요하면 Mac의 사진 앱에도 보이게 넣을 수 있어요.
02 · 📚 모음 · 🙂 얼굴로 묶기

복사하지 않는 링크 모음, 한 장이 여러 모음에

  • 모음은 링크라 원본을 복사하지 않아요. 같은 사진이 거래처 모음과 프로젝트 모음에 동시에 들어가도 용량은 그대로.
  • 자동 모음(Mac 안 AI): 사람 · 동물 · 캐릭터·그림 · 문서·영수증 · 스크린샷(화면 크기·이름별) · 동영상. 직접 만드는 수동 모음도.
  • 얼굴로 묶기: 비슷한 얼굴을 Mac에서 묶어 보여 주고, 이름을 붙이면 👤 사람 모음이 됩니다. 묶음은 추정이라 확인 후 쓰세요.
  • 얼굴 데이터는 사진첩 폴더 안에만 저장되고 어디로도 보내지 않아요.
03 · SD 카드 백업

카메라 카드 → 외장하드, 확인까지

  • SD 카드의 사진·영상을 외장하드로 복사한 뒤 다시 읽어 원본과 같은지 검증합니다.
  • 검증이 끝나면 이제 카드를 지워도 되는지 알려 줘요. 앱이 카드를 대신 지우지는 않습니다.
04 · 폰 백업

안드로이드 폰 → 외장하드, 메신저 사진까지

  • USB로 연결한 안드로이드 폰의 사진·동영상을 외장하드로 옮겨요 (adb 필요, Mac과 폰 사이에서만 동작).
  • 카메라 앨범뿐 아니라 카카오톡 · LINE · WhatsApp · WeChat · Zalo로 받은 사진·파일도.
05 · 외장하드 정리

중복·잡파일을 걸러 연·월별로

  • 중복과 쓸모없는 잡파일을 찾아 보여 주고, 남길 것은 연도·월 폴더로 정리합니다.
  • 정리한 작업은 기록이 남아 되돌릴 수 있어요.
06 · 백업 · 공간 확보

먼저 백업, 확인한 다음 Mac 비우기

  • 원본을 외장하드 또는 내 Google Drive로 올린 뒤, Mac의 공간을 확보합니다.
  • 원본은 검증이 끝난 뒤에만 휴지통으로 옮겨요 — 바로 지우지 않습니다.
  • Google Drive를 고르면 그 파일은 내 Google 계정으로 올라갑니다 (아래 데이터 안내 참고).
07 · 작업 기록

옮기고 지운 모든 파일, 검증 가능한 기록으로

  • 옮기거나 지운 파일의 경로·크기·MD5를 남기고, 기록끼리 해시 체인으로 이어 중간에 고쳐지면 드러나게 했어요.
  • 나중에 파일이 그대로인지 다시 확인할 수 있고, 기록은 이 Mac에만 저장됩니다.
08 · 가져오기

Google 포토 · Mac 사진 앱에서

  • Mac 사진 앱에서 선택한 사진, 앨범, 또는 보관함 전체에서 기간을 정해 가져오기.
  • Google 포토에서는 Google 화면에서 직접 고른 사진만 받아요. 지금은 시범 운영이라 계정 등록이 필요합니다 (hello@baryon.ai).
  • 폰·컴퓨터별 가져오는 방법은 가이드에 정리돼 있어요.
09 · 공유 · 글

PDF·Word로 내보내고, 글은 요청할 때만

  • 앨범을 PDF나 Word 문서로 만들어 보고서·공유용으로 (Mac 안에서 변환).
  • 소개 글은 누를 때만 내 Claude 계정의 Claude가 초안을 씁니다. 쓰지 않으면 아무것도 보내지 않아요.

MAC 안백업·정리·작업 기록

SD 카드·폰 백업, 외장하드 정리, 작업 기록은 Mac과 연결한 기기 안에서만 처리하며 파일 내용·이름을 보내지 않아요.

🍎 Mac

  1. DMG를 내려받아 엽니다

    위의 Mac용 다운로드를 누르고, 받은 파일을 더블클릭하세요.

  2. Applications 폴더로 끌어다 놓습니다

    열린 창에서 「주말 사진첩」 아이콘을 옆의 Applications 폴더 위로 옮기면 설치됩니다. 처음 열 때 🗂 프로페셔널을 고르세요.

  3. 처음 한 번 "그래도 열기"

    "확인되지 않은 개발자" 안내가 나오면 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 그래도 열기를 누르세요. "손상되었기 때문에 열 수 없습니다"라고 나오면 터미널에 아래 한 줄을 붙여 넣고 다시 여세요.

    xattr -dr com.apple.quarantine "/Applications/주말 사진첩.app"

🪟 Windows 10/11

  1. 설치 파일을 실행합니다

    위의 Windows용 다운로드로 받은 WeekendAlbum-1.15.0-Setup.exe를 더블클릭하세요. 관리자 권한은 필요 없고, 내 계정에만 설치됩니다.

  2. 처음 한 번 "추가 정보 → 실행"

    Windows의 PC 보호 창이 뜨면 추가 정보를 누른 뒤 실행을 누르세요. 아직 인증서 서명이 없는 새 앱이라 처음 한 번만 나옵니다.

  3. 「주말 사진첩」을 열고 보기를 고릅니다

    시작 메뉴(또는 바탕화면)의 주말 사진첩을 열고 가족·프로페셔널 중 고르세요. 사진은 사진(Pictures)\주말 사진첩 폴더에 모입니다. Windows 10에서 창이 비어 있으면 Microsoft Edge WebView2 런타임을 설치하고 다시 여세요.

  4. (선택) 동영상·안드로이드 폰 도구

    동영상 장면·클립과 폰 백업을 쓰려면 PowerShell에 아래 줄을 붙여 넣어 무료 도구를 설치하세요. 얼굴로 묶기·사진 내용 AI 분류·사진 앱 연동은 Mac에서만 됩니다.

    winget install Gyan.FFmpeg
    winget install Google.PlatformTools
