SD 카드 백업

카드를 꽂으면, 지워도 되는지까지 알려 줘요

카메라나 블랙박스 SD 카드를 꽂고 외장하드를 고르면, 카드 폴더 그대로 복사한 뒤 외장하드에서 다시 읽어 원본과 똑같은지 확인합니다. 모두 확인되면 “✅ 이 카드는 지워도 됩니다”.

  • 카드 한 장 = 폴더 하나. 같은 카드는 다음에 새 파일만 더해요
  • 숨김 폴더·카드 휴지통까지 빠짐없이
  • “꺼내고 다음 카드 백업” 버튼 하나로 여러 장을 연달아
폰 백업

폰 속 다운로드·카톡 파일, 외장하드로 옮겨 공간 확보

안드로이드 폰을 케이블로 연결하면 다운로드, 카메라, 카톡으로 받은 파일을 폴더별로 골라 외장하드로 옮깁니다. 폰과 외장하드 양쪽의 내용을 비교해 확인하고, 원하면 확인된 파일만 폰에서 지워요. 새로 찍은 사진은 주말 사진첩에 자동으로 들어가고, 원본은 외장하드에 있어 Mac 공간을 거의 쓰지 않아요.

  • 옮긴 뒤 바뀐 파일은 지우지 않아요
  • 처음 한 번 폰의 ‘USB 디버깅’만 켜면 돼요
  • 아이폰은 케이블로 Mac의 ‘이미지 캡처’·‘사진’ 앱에서 가져오고, iCloud에만 있는 원본은 ‘사진’ 앱에서 내보내요 · 폰·컴퓨터별 가져오는 방법 →
외장하드 정리

뒤죽박죽 외장하드, 보고서부터 보여 드려요

외장하드를 살펴 중복 파일, 잡파일, 빈 폴더, 폴더별 용량을 먼저 보고서로 보여 줍니다. 남길 파일만 고르면 나머지는 보관함으로, 흩어진 사진·동영상은 연/월 폴더로 정리돼요.

  • 내용 전체가 똑같은 파일만 중복으로 봐요
  • 모든 정리는 버튼 하나로 되돌리기
  • SD 카드 백업 폴더와 Time Machine 디스크는 건드리지 않아요
Mac 공간 확보

꽉 찬 Mac, 사진첩은 그대로 두고 공간만 비우기

사진첩을 외장하드에 백업한 뒤 Mac 공간 비우기를 누르면, 확인된 원본만 Mac에서 비우고 미리보기는 그대로 남겨요. 원본·동영상은 외장하드를 연결하면 바로 열립니다. 홈 폴더의 큰 사진·동영상 폴더도 골라서 외장하드로 옮길 수 있어요.

  • 지우기 직전에 외장하드 사본을 다시 읽어 확인
  • 언제든 'Mac으로 다시 가져오기'
  • 사진 앱 보관함·코드 프로젝트·사진첩 폴더는 옮기지 않아요
  • 휴지통을 비우기 전까지 되돌릴 수 있어요
  • Google Drive 백업 후 정리도 함께
작업 기록

무엇을 어디로 옮겼는지, 몇 달 뒤에도 확인

옮기고 지운 모든 작업이 파일 하나하나까지 기록돼요. 나중에 결과 다시 확인을 누르면 외장하드에 지금도 그대로 있는지 보여 주고, 기록 자체가 고쳐지거나 빠지지 않았는지도 검사합니다.

  • 파일마다 원래 위치·새 위치·크기·MD5
  • 기록끼리 해시로 이어져 있어 위조·누락이 드러나요
  • 기록은 내 Mac에만 저장돼요
사진첩 만들기

사진은 고르기만 하세요

주말마다 한 권

토·일에 찍은 사진은 "8월 3째주"처럼 주말별로, 평일 사진은 "9월 평일"처럼 달별로 나눕니다. 여행처럼 내가 정한 묶음도 만들 수 있어요.

어디서 온 사진이든

Google 포토에서 고르거나, 카톡으로 받은 사진을 끌어다 놓으면 촬영 날짜를 읽어 제자리에 넣습니다. 누가 찍었는지도 적어 둘 수 있어요.

언제·어디서까지 담은 소개 글

사진의 위치(동네 이름), 날짜·시간대·명절, 간판에 적힌 글자까지 모아 그날의 흐름을 만들고, Claude가 그대로 일기처럼 초안을 써 줘요. 내 말로 고쳐서 완성하면 돼요.

포토북과 PDF

대표 사진 몇 장을 고르면 포토북 화면이 되고, 여러 주말을 묶어 PDF 한 파일로 가족에게 보낼 수 있습니다.

나만의 인스타 · Mac 안 AI

베스트 사진, 해시태그, 어울리는 노래를 Mac 안의 AI(Apple Vision · Laya)가 몇 초 만에 골라요. 인터넷으로 사진을 보내지 않아요. 노래는 30초 미리듣기로 작게 흘러요.

중복 정리와 공간 확보

카톡으로 다시 받은 같은 사진을 찾아 휴지통으로 옮기고, 백업한 원본을 정리해 Mac 저장 공간을 비워 줍니다.

설치

3단계면 끝나요

앱 스토어 밖에서 받는 앱이라 처음 한 번만 Mac의 확인 절차를 거칩니다.

  1. DMG를 내려받아 엽니다

    위의 Mac용 다운로드를 누르고, 받은 파일을 더블클릭하세요.

  2. Applications 폴더로 끌어다 놓습니다

    열린 창에서 「주말 사진첩」 아이콘을 옆의 Applications 폴더 위로 옮기면 설치됩니다.

  3. 처음 한 번 "그래도 열기"

    "확인되지 않은 개발자" 안내가 나오면 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 그래도 열기를 누르세요. "손상되었기 때문에 열 수 없습니다"라고 나오면 터미널에 아래 한 줄을 붙여 넣고 다시 여세요.

    xattr -dr com.apple.quarantine "/Applications/주말 사진첩.app"

사진과 개인정보

사진은 내 Mac에만 있어요

사진은 올라가지 않아요

사진첩은 내 Mac의 사진 폴더에 만들어집니다. Baryon Labs 서버로 사진·글·메모를 보내지 않아요.

대부분은 Mac 안에서

사진 고르기·태그·노래는 Mac 안의 AI가 해요. 글을 써 달라고 누를 때만 고른 사진 몇 장과 '언제·어디서' 요약(동네 이름까지)이 내 Claude 계정으로 갑니다. 원본·파일 이름·GPS 좌표는 보내지 않아요.

모든 작업은 기록으로

옮기고 지운 파일의 위치·크기·MD5가 이 Mac에만 남아, 나중에 그대로인지 다시 확인할 수 있어요.
