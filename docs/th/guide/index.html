การนำรูปออกจากโทรศัพท์

วิธีจะต่างกันไปตามมือถือและคอมพิวเตอร์ที่ใช้ เลือกกรณีของคุณแล้วทำตามได้เลย นำโฟลเดอร์ที่ได้มาใส่ด้วย อัปโหลดรูปที่ได้รับ ในอัลบั้มสุดสัปดาห์ แล้วรูปจะถูกจัดตามวันที่ให้

Mac

iPhone → Mac (สายเคเบิล)

  1. เสียบสาย ปลดล็อก iPhone แล้วแตะ เชื่อถือ ที่ "เชื่อถือคอมพิวเตอร์นี้หรือไม่"
  2. เปิดแอป จับภาพ (Image Capture) บน Mac (หรือ รูปภาพ → นำเข้า) แล้วเลือก iPhone
  3. เลือกโฟลเดอร์ปลายทาง แล้วคลิก ดาวน์โหลดทั้งหมด
  4. ในอัลบั้มสุดสัปดาห์ ใส่โฟลเดอร์นั้นด้วย อัปโหลดรูปที่ได้รับ

เคล็ดลับ การตั้งค่า iPhone → รูปภาพ → "ถ่ายโอนไปยัง Mac หรือ PC": เลือก เก็บต้นฉบับ เพื่อให้ได้ไฟล์ HEIC ตามเดิม ("อัตโนมัติ" จะแปลงเป็น JPG) ส่วน Live Photo จะมาเป็นรูป + วิดีโอสั้น

iPhone · รูปภาพ iCloud → Mac

  1. ถ้าเปิด ปรับพื้นที่จัดเก็บ iPhone ให้เหมาะสม ไว้ ในมือถือจะมีแค่สำเนาขนาดเล็ก ต้นฉบับอยู่ใน iCloud
  2. บน Mac เปิด การตั้งค่าระบบ → บัญชี Apple → iCloud → รูปภาพ (บัญชี Apple เดียวกัน) แล้วเลือกรูปในแอป รูปภาพ
  3. ไฟล์ → ส่งออก → ส่งออกต้นฉบับที่ไม่ได้แก้ไข ไปยังโฟลเดอร์
  4. ใส่โฟลเดอร์นั้นด้วย อัปโหลดรูปที่ได้รับ

เคล็ดลับ ถ้าพื้นที่ Mac ไม่พอ จะเลือกดาวน์โหลดจาก iCloud.com → รูปภาพ ก็ได้

Android → Mac

  1. ครั้งแรกเท่านั้น: รัน brew install --cask android-platform-tools ใน Terminal แล้วเปิด การแก้ไขข้อบกพร่อง USB (USB debugging) ในตัวเลือกสำหรับนักพัฒนาของมือถือ
  2. เสียบสายแล้วแตะ อนุญาตการแก้ไขข้อบกพร่อง USB บนมือถือ
  3. ในแท็บ สำรองโทรศัพท์ ของอัลบั้มสุดสัปดาห์ เลือกโฟลเดอร์ (กล้อง ดาวน์โหลด รูปจาก LINE และ KakaoTalk ใน Pictures…) แล้วย้าย — รูปใหม่จะเข้าอัลบั้มให้อัตโนมัติ
  4. ถ้าต้องการ ลบออกจากมือถือ — เฉพาะไฟล์ที่ตรวจสอบแล้ว

เคล็ดลับ ถ้าต้องการแค่รูป ตั้งโหมด USB ของมือถือเป็น ถ่ายโอนรูปภาพ (PTP) แล้วใช้แอปจับภาพบน Mac

รูปใน Google Photos (ทั้ง iPhone และ Android)

  1. คลิก นำเข้ารูปจาก Google Photos ในอัลบั้มสุดสัปดาห์
  2. เลือกรูปในหน้าต่าง Google Photos ที่เปิดขึ้น
  3. ระบบจะดาวน์โหลดเฉพาะรูปที่เลือก แล้วจัดเข้าอัลบั้มตามวันที่

เคล็ดลับ ตามนโยบายของ Google แอปภายนอกรับได้เฉพาะรูปที่คุณเลือกเอง ถ้ามีจำนวนมาก ให้ใช้ Google Takeout

Windows PC

ตอนนี้อัลบั้มสุดสัปดาห์มีเฉพาะบน Mac (กำลังเตรียมเวอร์ชัน Windows) บน Windows ให้นำรูปมาไว้ใน PC ก่อน

iPhone → Windows PC

  1. ติดตั้งแอป Apple Devices จาก Microsoft Store (ไดรเวอร์สำหรับเชื่อมต่อ iPhone)
  2. เสียบสายแล้วแตะ เชื่อถือ บน iPhone
  3. แอป รูปถ่าย (Photos) ของ Windows → นำเข้า → มือถือ หรือ File Explorer → Apple iPhone → Internal Storage → DCIM แล้วคัดลอก

เคล็ดลับ ใช้รูปภาพ iCloud อยู่? รับต้นฉบับด้วย iCloud สำหรับ Windows ถ้าเปิด HEIC ไม่ได้ ให้ติดตั้ง "HEIF Image Extensions" จาก Microsoft Store หรือตั้งค่าการถ่ายโอนของ iPhone เป็น "อัตโนมัติ" (JPG)

Android → Windows PC

  1. เสียบสายแล้วเลือก ถ่ายโอนไฟล์ (MTP) ในการแจ้งเตือน USB ของมือถือ
  2. File Explorer → ชื่อมือถือ → ที่จัดเก็บข้อมูลภายใน
  3. คัดลอก DCIM/Camera (รูปถ่าย) โฟลเดอร์ LINE และแอปแชตอื่นใน Pictures และ Download ไปยัง PC

เคล็ดลับ ใช้การนำเข้าของแอป รูปถ่าย ใน Windows, Phone Link หรือ Smart Switch สำหรับมือถือ Samsung ก็ได้
