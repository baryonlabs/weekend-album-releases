포토북과 PDF

나만의 인스타

주말마다 베스트 사진, 짧은 글, 해시태그, 어울리는 노래를 골라 피드처럼 보여 줍니다. 노래는 30초 미리듣기로 작게 흘러요.

중복 정리와 공간 확보

카톡으로 다시 받은 같은 사진을 찾아 휴지통으로 옮기고, 백업한 원본을 정리해 Mac 저장 공간을 비워 줍니다.

설치

3단계면 끝나요

앱 스토어 밖에서 받는 앱이라 처음 한 번만 Mac의 확인 절차를 거칩니다.

  1. DMG를 내려받아 엽니다

    위의 Mac용 다운로드를 누르고, 받은 파일을 더블클릭하세요.

  2. Applications 폴더로 끌어다 놓습니다

    열린 창에서 「주말 사진첩」 아이콘을 옆의 Applications 폴더 위로 옮기면 설치됩니다.

  3. 처음 한 번 "그래도 열기"

    "확인되지 않은 개발자" 안내가 나오면 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 그래도 열기를 누르세요. "손상되었기 때문에 열 수 없습니다"라고 나오면 터미널에 아래 한 줄을 붙여 넣고 다시 여세요.

    xattr -dr com.apple.quarantine "/Applications/주말 사진첩.app"

사진은 올라가지 않아요

사진첩은 내 Mac의 사진 폴더에 만들어집니다. Baryon Labs 서버로 사진·글·메모를 보내지 않아요.

AI는 누를 때만

소개 글이나 인스타 추천을 요청할 때만, 작게 줄인 사진 모음이 내 Claude 계정으로 전송됩니다. 원본·파일 이름·위치 정보는 보내지 않아요.
