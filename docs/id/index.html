Intip dulu

Begini tampilannya

Layar di bawah adalah album demo dengan gambar contoh (Unsplash, Lorem Picsum). Aplikasinya bisa dipakai dalam Bahasa Indonesia, Inggris, Korea, Jepang, Thai, Vietnam, dan Mandarin (sederhana & tradisional).

Lebih dari album

Makin banyak foto, makin banyak pikiran. Biar sebagian kami yang urus.

Kartu kamera, ponsel, hard disk eksternal, Mac yang penuh. Tidak ada yang dihapus sebelum diperiksa, dan semuanya bisa dibatalkan.

Cadangan Kartu SD

Colok kartunya. Nanti dikabari kapan aman dihapus.

Masukkan kartu SD kamera atau dashcam, lalu pilih hard disk eksternal. Folder di kartu disalin apa adanya, lalu dibaca ulang dari hard disk untuk memastikan sama persis dengan aslinya. Kalau semua cocok: “✅ Kartu ini aman untuk dihapus.”

  • Satu kartu = satu folder. Lain kali, kartu yang sama hanya menambah file baru
  • Folder tersembunyi dan tempat sampah di kartu ikut tersalin. Tidak ada yang tertinggal
  • Cadangkan banyak kartu berturut-turut dengan “Keluarkan dan cadangkan kartu berikutnya”
Cadangan Ponsel

Unduhan dan file chat keluar dari ponsel, ruangnya kembali

Colokkan ponsel Android dan pilih folder (Download, Kamera, WhatsApp, Telegram, juga KakaoTalk) untuk dipindah ke hard disk eksternal. Kedua sisi dibandingkan, dan kalau mau, hanya file yang sudah terverifikasi yang dihapus dari ponsel. Foto baru otomatis masuk ke Album Akhir Pekan, sementara file aslinya tetap di hard disk, jadi hampir tidak memakan ruang Mac.

  • File yang berubah setelah disalin tidak akan pernah dihapus
  • Cukup nyalakan “Debugging USB” di ponsel, sekali saja
  • Pakai iPhone? Impor lewat kabel dengan Tangkap Gambar (Image Capture) atau Foto; file asli yang hanya ada di iCloud diekspor dari aplikasi Foto · Cara impor, per ponsel & komputer →
Rapikan Hard Disk

Hard disk eksternal berantakan? Kamu dapat laporannya dulu.

Hard disk dipindai dan kamu diperlihatkan duplikat, file sampah, folder kosong, dan besar ruang tiap folder, sebelum ada yang dipindah. Pilih yang mau disimpan, sisanya masuk folder penampungan; foto dan video yang tercecer dirapikan ke folder tahun/bulan.

  • Hanya file yang identik sampai ke tiap byte yang dianggap duplikat
  • Setiap perapian bisa dibatalkan dengan satu tombol
  • Folder cadangan kartu SD dan disk Time Machine tidak disentuh
Cadangkan & Kosongkan Ruang

Mac penuh? Albumnya tetap, beratnya hilang.

Cadangkan album ke hard disk eksternal, lalu tekan Kosongkan ruang Mac. Hanya file asli yang sudah terverifikasi yang dihapus dari Mac, dan pratinjaunya tetap ada. File asli dan video langsung terbuka setiap kali hard disk tersambung. Kamu juga bisa memilih folder foto dan video besar di folder rumah dan memindahkannya ke hard disk.

  • Salinan di hard disk dibaca ulang sekali lagi tepat sebelum menghapus
  • “Kembalikan ke Mac” kapan pun kamu mau
  • Perpustakaan Foto, proyek kode, dan folder album tidak pernah dipindah
  • Bisa dibatalkan selama Tong Sampah belum dikosongkan
  • Cadangkan ke Google Drive dan rapikan sekaligus
Log Aktivitas

Apa pindah ke mana? Masih bisa dijawab berbulan-bulan kemudian.

Setiap pemindahan dan penghapusan dicatat sampai ke tiap file. Nanti, ketuk periksa hasil lagi untuk melihat semuanya masih ada di hard disk, dan memastikan lognya sendiri tidak diubah atau ada catatan yang hilang.

  • Lokasi asal, lokasi baru, ukuran, dan MD5 untuk setiap file
  • Catatan saling terkait dengan hash, jadi perubahan atau celah akan ketahuan
  • Log hanya disimpan di Mac-mu

Instal

Tiga langkah, beres

Aplikasinya bukan dari App Store, jadi Mac akan minta konfirmasi sekali, hanya saat pertama kali.

🍎 Mac

  1. Unduh dan buka DMG-nya

    Klik Unduh untuk Mac di atas, lalu klik dua kali file yang terunduh.

  2. Seret ke Aplikasi

    Di jendela yang terbuka, seret ikon Album Akhir Pekan (namanya tampil sebagai “주말 사진첩”) ke folder Aplikasi di sebelahnya.

  3. Pertama kali, “Tetap Buka”

    Kalau macOS bilang tidak bisa memverifikasi aplikasi atau pengembangnya, buka Pengaturan Sistem → Privasi & Keamanan, gulir ke paling bawah, lalu klik Tetap Buka. Kalau muncul pesan aplikasi “rusak dan tidak dapat dibuka”, tempel baris di bawah ke Terminal, lalu buka aplikasinya lagi.

    xattr -dr com.apple.quarantine "/Applications/주말 사진첩.app"

🪟 Windows 10/11

  1. Jalankan installer

    Klik dua kali WeekendAlbum-1.15.1-Setup.exe dari Unduh untuk Windows di atas. Tidak perlu hak admin — hanya terpasang untuk akun Anda.

  2. Pertama kali: "Info selengkapnya → Tetap jalankan"

    Jika muncul Windows protected your PC, klik Info selengkapnya lalu Tetap jalankan. Aplikasinya baru dan belum bersertifikat tanda tangan, jadi hanya muncul sekali. Jika Windows 11 menampilkan “Kebijakan Kontrol Aplikasi telah memblokir file ini” (Smart App Control), versi ini belum bisa dijalankan — gunakan versi Microsoft Store yang segera hadir.

  3. Buka aplikasi dan pilih tampilan

    Buka Album Akhir Pekan dari menu Start (atau desktop) lalu pilih Keluarga atau Profesional. Foto dikumpulkan di Pictures\주말 사진첩. Di Windows 10, jika jendela kosong, pasang Microsoft Edge WebView2 Runtime lalu buka lagi.

  4. (Opsional) Alat video & ponsel Android

    Untuk adegan/klip video dan cadangan ponsel, tempel baris di bawah ke PowerShell untuk memasang alat gratis. Kelompok wajah, pemilahan isi foto dengan AI, dan sinkron app Foto hanya di Mac.

    winget install Gyan.FFmpeg
    winget install Google.PlatformTools

Foto & privasi

Albummu tinggal di Mac-mu

Tidak ada yang masuk ke server kami

Album dibuat di folder Gambar di Mac-mu. Baryon Labs tidak pernah menerima foto, cerita, atau catatanmu. Foto keluar dari Mac hanya kalau kamu memilihnya, misalnya saat mencadangkan ke Google Drive milikmu sendiri.

Sebagian besar di Mac

Pemilihan foto, tagar, dan lagu ditangani AI di Mac-mu. Hanya saat kamu minta dituliskan, beberapa foto terpilih dan ringkasan “kapan & di mana” (sampai tingkat kelurahan) dikirim ke akun Claude-mu. File asli, nama file, dan koordinat GPS tidak dikirim.

Setiap tindakan dicatat

Lokasi, ukuran, dan MD5 setiap file yang dipindah atau dihapus disimpan hanya di Mac ini, jadi nanti kamu bisa memastikan semuanya masih utuh.

Hanya hitungan penggunaan anonim

Baryon Labs hanya menerima hitungan anonim tentang fitur mana yang dipakai dan seberapa sering. Kamu bisa melihat persis apa yang akan dikirim, dan mematikannya, di “ⓘ Info” dalam aplikasi.

Detailnya ada di “ⓘ Info” dalam aplikasi → catatan data & AI, Ketentuan Penggunaan, dan Kebijakan Privasi. Album Akhir Pekan gratis untuk keperluan pribadi, keluarga, maupun pekerjaan.
