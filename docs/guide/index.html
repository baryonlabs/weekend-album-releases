폰 사진 가져오기 (폰·컴퓨터별)

폰과 컴퓨터에 따라 방법이 다릅니다. 내 경우를 찾아 따라 하세요. 가져온 폴더는 주말 사진첩의 받은 사진 올리기로 넣으면 날짜별로 정리됩니다.

Mac

아이폰 → Mac (케이블)

  1. 케이블로 연결하고 아이폰 잠금을 풀어 이 컴퓨터를 신뢰 → 신뢰를 누릅니다.
  2. Mac의 이미지 캡처 앱(또는 사진 앱 → 가져오기)에서 아이폰을 고릅니다.
  3. 받을 폴더를 정하고 모두 다운로드.
  4. 주말 사진첩에서 받은 사진 올리기로 그 폴더를 넣습니다.

팁 아이폰 설정 → 사진 → 'Mac 또는 PC로 전송'을 원본 유지로 하면 HEIC 그대로 옵니다 ('자동'은 JPG로 바꿈). Live Photo는 사진·동영상 두 파일로 옵니다.

아이폰 · iCloud 사진 → Mac

  1. iCloud 사진에서 iPhone 저장 공간 최적화가 켜져 있으면 폰에는 작은 사본만 있어요. 원본은 iCloud에 있습니다.
  2. Mac의 시스템 설정 → Apple 계정 → iCloud → 사진을 켜고(같은 Apple 계정), 사진 앱에서 사진을 고릅니다.
  3. 파일 → 내보내기 → 수정되지 않은 원본 내보내기 로 폴더에 꺼냅니다.
  4. 그 폴더를 받은 사진 올리기로 넣습니다.

팁 Mac 공간이 부족하면 iCloud.com → 사진에서 골라 내려받아도 됩니다.

안드로이드 → Mac

  1. 처음 한 번: 터미널에서 brew install --cask android-platform-tools, 폰에서 개발자 옵션 → USB 디버깅 켜기.
  2. 케이블로 연결하고 폰의 USB 디버깅 허용을 누릅니다.
  3. 주말 사진첩 폰 백업 탭에서 폴더(카메라·다운로드·카톡 등)를 고르고 옮깁니다 — 새로 찍은 사진은 사진첩에 자동으로 들어가요.
  4. 원하면 확인된 파일만 폰에서 지우기.

팁 사진만 필요하면: 폰 알림의 USB 모드를 사진 전송(PTP) 으로 하고 Mac의 이미지 캡처로 가져와도 됩니다.

Google 포토에 올려 둔 사진 (아이폰·안드로이드 모두)

  1. 주말 사진첩의 Google 포토에서 사진 가져오기를 누릅니다.
  2. 열린 Google 포토 창에서 가져올 사진을 고릅니다.
  3. 고른 사진만 내려받아 날짜별 사진첩으로 정리됩니다.

팁 Google 정책상 외부 앱은 사람이 고른 사진만 받을 수 있어요. 아주 많은 양은 Google 테이크아웃으로 내려받으세요.

Windows PC

주말 사진첩은 지금 Mac용입니다 (Windows판 준비 중). Windows에서는 사진을 먼저 PC로 가져와 두세요.

아이폰 → Windows PC

  1. Microsoft Store에서 Apple Devices 앱을 설치합니다 (아이폰 연결 드라이버).
  2. 케이블로 연결하고 아이폰에서 신뢰를 누릅니다.
  3. Windows 사진 앱 → 가져오기 → 휴대폰, 또는 파일 탐색기 → Apple iPhone → Internal Storage → DCIM 에서 복사합니다.

팁 iCloud 사진을 쓴다면 Windows용 iCloud로 원본을 받으세요. HEIC가 안 열리면 Microsoft Store의 'HEIF 이미지 확장'을 설치하거나 아이폰 전송 설정을 '자동'(JPG)으로.

안드로이드 → Windows PC

  1. 케이블로 연결하고 폰 알림의 USB 모드에서 파일 전송(MTP) 을 고릅니다.
  2. 파일 탐색기 → 폰 이름 → 내부 저장소로 들어갑니다.
  3. DCIM/Camera(사진), Pictures/KakaoTalk(카톡), Download(다운로드)를 PC로 복사합니다.

팁 Windows 사진 앱의 가져오기나 휴대폰과 연결(Phone Link), 삼성 폰은 Smart Switch도 쓸 수 있어요.
