Getting photos off your phone

The method depends on your phone and computer. Find your case and follow along. Add the imported folder with Upload received photos in Weekend Album and it's sorted by date.

iPhone → Mac (cable)iPhone · iCloud Photos → MacAndroid → MacPhotos in Google Photos (iPhone & Android)iPhone → Windows PCAndroid → Windows PC

Mac

iPhone → Mac (cable)

  1. Connect by cable, unlock the iPhone and tap Trust on "Trust This Computer?".
  2. Open the Mac's Image Capture app (or Photos → Import) and pick the iPhone.
  3. Choose a folder and click Download All.
  4. In Weekend Album, add that folder with Upload received photos.

Tip iPhone Settings → Photos → "Transfer to Mac or PC": Keep Originals keeps HEIC ("Automatic" converts to JPG). A Live Photo arrives as a photo + a short video.

iPhone · iCloud Photos → Mac

  1. With Optimize iPhone Storage on, the phone keeps only small copies — the originals are in iCloud.
  2. On the Mac, turn on System Settings → Apple Account → iCloud → Photos (same Apple Account) and select photos in the Photos app.
  3. File → Export → Export Unmodified Original to a folder.
  4. Add that folder with Upload received photos.

Tip Short on Mac space? You can also pick and download from iCloud.com → Photos.

Android → Mac

  1. First time only: run brew install --cask android-platform-tools in Terminal, and turn on USB debugging in the phone's Developer options.
  2. Connect by cable and tap Allow USB debugging on the phone.
  3. In Weekend Album's Phone Backup tab, pick folders (camera, downloads, messengers…) and move them — new photos go into your albums automatically.
  4. Optionally delete from the phone — only verified files.

Tip Photos only? Set the phone's USB mode to Transfer photos (PTP) and use the Mac's Image Capture.

Photos in Google Photos (iPhone & Android)

  1. Click Import photos from Google Photos in Weekend Album.
  2. Pick photos in the Google Photos window that opens.
  3. Only the photos you picked are downloaded and sorted into albums by date.

Tip By Google's policy, apps only receive photos you pick. For very large amounts, use Google Takeout.

Windows PC

Weekend Album is Mac-only for now (a Windows version is in the works). On Windows, bring photos to the PC first.

iPhone → Windows PC

  1. Install the Apple Devices app from the Microsoft Store (iPhone connection drivers).
  2. Connect by cable and tap Trust on the iPhone.
  3. Windows Photos app → Import → phone, or File Explorer → Apple iPhone → Internal Storage → DCIM and copy.

Tip Using iCloud Photos? Get originals with iCloud for Windows. If HEIC won't open, install "HEIF Image Extensions" from the Microsoft Store, or set the iPhone transfer option to "Automatic" (JPG).

Android → Windows PC

  1. Connect by cable and choose File transfer (MTP) in the phone's USB notification.
  2. File Explorer → your phone → Internal storage.
  3. Copy DCIM/Camera (photos), messenger folders under Pictures, and Download to the PC.

Tip You can also use the Windows Photos app's Import, Phone Link, or Smart Switch on Samsung phones.
