개인정보 처리방침

시행일: 2026년 10월 2일 · 버전 1.0.0

Baryon Labs(바리온랩스, 이하 "회사")는 주말 사진첩과 Photo Offload(이하 "앱")를 이용하는 분의 개인정보를 소중히 다룹니다.

1. 회사가 받는 정보: 익명 사용량 통계뿐

회사는 익명 사용량 통계(무작위 설치 ID, 앱 버전, macOS 버전, 날짜별 기능 사용 횟수)만 받습니다. 사진·동영상, 파일·앨범 이름, 글·메모, 계정·이메일·사람 이름·위치는 받지 않으며, 광고·추적 기능은 없습니다.

  • 목적: 기능 사용 현황 파악과 앱 개선. 다른 목적 이용·제3자 제공·판매 없음.
  • 보내는 내용은 앱 「정보」 화면에서 글자 그대로 확인할 수 있고, 언제든 끌 수 있습니다(끄면 보내지 않은 기록도 삭제).
  • 수집 서버에 전달되는 IP 주소는 통계에 저장하거나 설치 ID와 연결하지 않습니다.
  • 받은 통계는 앱 개선에 필요한 기간(최대 2년) 동안 보관한 뒤 지웁니다.

3. 이용자가 실행할 때 외부 서비스로 보내는 정보

Google(사진 가져오기·Drive 백업), Apple(노래 미리듣기 검색: 곡명·가수만), Anthropic(Claude — 글을 써 달라고 할 때만), Hugging Face(Laya 모델 받기, 받기만 함), Apple 지도(소개 글을 쓸 때 사진 위치 → 동네 이름, PDF의 작은 지도)로 무엇을 보내고 AI가 무엇을 처리하는지는 「데이터·AI 안내」에 기능별로 빠짐없이 적었습니다. 이 정보는 회사가 아니라 이용자의 계정으로 각 서비스에 직접 전송되며, 각 서비스의 약관과 개인정보 처리방침이 적용됩니다. 해당 기능을 쓰지 않으면 보내지 않습니다.

4. 다른 사람의 정보

다른 사람이 찍은 사진, 사진 속 인물, "찍은 사람" 이름은 이용자의 Mac에만 저장됩니다. 이를 공유(PDF 등)할 때는 당사자의 동의를 받아 주세요.

5. 정보의 삭제

  • 사용 통계는 「정보」 화면에서 끄면 Mac에 남은 기록이 바로 지워집니다. 이미 받은 통계는 설치 ID(「정보」 화면에 표시)를 hello@baryon.ai로 알려 주시면 지워 드립니다.
  • 앱 안의 사진·자료는 앱의 삭제 기능(휴지통으로 이동) 또는 Finder에서 지울 수 있습니다.
  • Google 연결은 앱의 "로그아웃" 또는 Google 계정 설정의 "타사 앱 액세스"에서 해제할 수 있고, 위 2항의 토큰 파일을 지우면 Mac에 남은 로그인 정보도 사라집니다.
  • 앱을 지울 때 위 폴더를 함께 지우면 앱이 만든 모든 정보가 삭제됩니다.

6. 아동의 개인정보

가족 사진에 아동이 포함될 수 있습니다. 앱은 이를 외부로 보내지 않지만, 이용자가 AI 기능이나 공유 기능을 쓸 때는 보호자로서 신중히 판단해 주세요.

7. 변경
