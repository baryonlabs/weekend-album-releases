スマホの写真の取り込み（スマホ・パソコン別）

スマホとパソコンの組み合わせで方法が変わります。ご自分のケースを選んでください。取り込んだフォルダは週末アルバムの 受け取った写真をアップロード で入れると日付ごとに整理されます。

Mac

iPhone → Mac（ケーブル）

  1. ケーブルでつなぎ、iPhone のロックを解除して このコンピュータを信頼 → 信頼。
  2. Mac の イメージキャプチャ（または 写真 → 読み込む）で iPhone を選びます。
  3. 保存先フォルダを決めて すべてを読み込む。
  4. 週末アルバムの 受け取った写真をアップロード でそのフォルダを入れます。

ヒント iPhone の設定 → 写真 →「Mac または PC に転送」を 元のフォーマットのまま にすると HEIC のまま（「自動」は JPG に変換）。Live Photo は写真と動画の 2 ファイルです。

iPhone・iCloud 写真 → Mac

  1. iCloud 写真で iPhone のストレージを最適化 がオンだと、本体には小さなコピーしかありません。オリジナルは iCloud にあります。
  2. Mac の システム設定 → Apple アカウント → iCloud → 写真 をオン（同じ Apple アカウント）にし、写真 アプリで写真を選びます。
  3. ファイル → 書き出す → 編集されていないオリジナルを書き出す でフォルダへ。
  4. そのフォルダを 受け取った写真をアップロード で入れます。

ヒント Mac の空きが少ないときは iCloud.com → 写真 から選んでダウンロードしても OK です。

Android → Mac

  1. 初回のみ: ターミナルで brew install --cask android-platform-tools、スマホの開発者向けオプションで USB デバッグ をオン。
  2. ケーブルでつなぎ、スマホの USB デバッグを許可 をタップ。
  3. 週末アルバムの スマホのバックアップ タブでフォルダ（カメラ・ダウンロード・メッセンジャーなど）を選んで移します。新しい写真はアルバムに自動で入ります。
  4. 必要なら確認済みのファイルだけ スマホから削除。

ヒント 写真だけなら、USB モードを 写真を転送（PTP） にして Mac のイメージキャプチャで取り込めます。

Google フォトにある写真（iPhone・Android 共通）

  1. 週末アルバムの Google Photos から写真を取り込む をクリック。
  2. 開いた Google フォトの画面で写真を選びます。
  3. 選んだ写真だけがダウンロードされ、日付ごとのアルバムに整理されます。

ヒント Google の方針で、外部アプリは選んだ写真しか受け取れません。大量なら Google テイクアウトを使ってください。

Windows PC

週末アルバムは現在 Mac 版のみです（Windows 版を準備中）。Windows ではまず写真を PC に取り込んでおいてください。

iPhone → Windows PC

  1. Microsoft Store から Apple デバイス アプリをインストール（iPhone 接続用ドライバー）。
  2. ケーブルでつなぎ、iPhone で 信頼 をタップ。
  3. Windows の フォト アプリ → インポート → スマホ、またはエクスプローラー → Apple iPhone → Internal Storage → DCIM からコピー。

ヒント iCloud 写真なら Windows 用 iCloud でオリジナルを取得。HEIC が開けないときは Microsoft Store の「HEIF 画像拡張機能」を入れるか、iPhone の転送設定を「自動」（JPG）に。

Android → Windows PC

  1. ケーブルでつなぎ、スマホの通知の USB モードで ファイル転送（MTP） を選択。
  2. エクスプローラー → スマホ名 → 内部ストレージへ。
  3. DCIM/Camera（写真）、Pictures 内のメッセンジャーのフォルダ、Download を PC へコピー。

ヒント Windows の フォト のインポート、スマートフォン連携（Phone Link）、Samsung なら Smart Switch も使えます。
