從手機匯入照片

方法依手機和電腦而不同，找到你的情況照著做就好。匯入的資料夾用週末相簿的 上傳收到的照片 放進去，就會依日期整理好。

Mac

iPhone → Mac（傳輸線）

  1. 用傳輸線連接，解鎖 iPhone，在 要信任這部電腦嗎？ 提示中點信任。
  2. 在 Mac 的 影像擷取（或 照片 App → 輸入）中選擇 iPhone。
  3. 選好要存放的資料夾，點 全部下載。
  4. 在週末相簿用 上傳收到的照片 放入這個資料夾。

提示 iPhone 設定 → 照片 →「傳送到 Mac 或 PC」選 保留原始檔，就會以 HEIC 原樣傳過來（「自動」會轉成 JPG）。原況照片會變成照片和影片兩個檔案。

iPhone · iCloud 照片 → Mac

  1. 如果 iCloud 照片開著 最佳化 iPhone 儲存空間，手機裡只有縮小的副本，原始檔在 iCloud 上。
  2. 在 Mac 的 系統設定 → Apple 帳號 → iCloud → 照片 開啟（同一個 Apple 帳號），再到 照片 App 選好照片。
  3. 檔案 → 輸出 → 輸出未修改的原始檔，輸出到一個資料夾。
  4. 用 上傳收到的照片 放入這個資料夾。

提示 Mac 空間不夠的話，也可以到 iCloud.com → 照片 挑選後下載。

Android → Mac

  1. 第一次：在「終端機」執行 brew install --cask android-platform-tools，並在手機的開發人員選項開啟 USB 偵錯。
  2. 用傳輸線連接，在手機上點 允許 USB 偵錯。
  3. 在週末相簿的 手機備份 分頁選好資料夾（相機、下載、LINE 等）然後搬移——新拍的照片會自動放進相簿。
  4. 需要的話，只把核對過的檔案 從手機刪除。

提示 只要照片的話：把手機通知裡的 USB 模式設為 傳輸相片（PTP），用 Mac 的影像擷取匯入也可以。

存在 Google 相簿的照片（iPhone、Android 都適用）

  1. 點週末相簿的 從 Google 相簿匯入照片。
  2. 在打開的 Google 相簿視窗選好要匯入的照片。
  3. 只下載選好的照片，並依日期整理進相簿。

提示 依照 Google 的政策，外部 App 只能接收使用者親手挑選的照片。數量很多的話，請用 Google 匯出（Takeout）下載。

Windows PC

週末相簿目前只有 Mac 版（Windows 版準備中）。在 Windows 上，請先把照片匯入電腦。

iPhone → Windows 電腦

  1. 從 Microsoft Store 安裝 Apple 裝置 App（iPhone 連接驅動程式）。
  2. 用傳輸線連接，在 iPhone 上點 信任。
  3. 用 Windows 的 相片 App → 匯入 → 從連接的裝置，或在檔案總管 → Apple iPhone → Internal Storage → DCIM 裡複製。

提示 如果用 iCloud 照片，請用 Windows 版 iCloud 下載原始檔。HEIC 打不開的話，安裝 Microsoft Store 的「HEIF 影像延伸模組」，或把 iPhone 的傳送設定改成「自動」（JPG）。

Android → Windows 電腦

  1. 用傳輸線連接，在手機通知的 USB 模式選 檔案傳輸（MTP）。
  2. 打開檔案總管 → 手機名稱 → 內部儲存空間。
  3. 把 DCIM/Camera（相機照片）、Pictures 裡的 LINE 等聊天 App 資料夾、Download（下載）複製到電腦。

提示 也可以用 Windows 相片 App 的匯入、手機連結（Phone Link），三星手機還能用 Smart Switch。
