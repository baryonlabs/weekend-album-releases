从手机导入照片

方法因手机和电脑而异，找到你的情况照着做就行。导入的文件夹用周末相册的 上传收到的照片 放进去，就会按日期整理好。

iPhone → Mac（数据线）iPhone · iCloud 照片 → Mac安卓 → Mac存在 Google 相册里的照片（iPhone、安卓通用）iPhone → Windows 电脑安卓 → Windows 电脑

Mac

iPhone → Mac（数据线）

  1. 用数据线连接，解锁 iPhone，在 要信任此电脑吗？ 提示中点信任。
  2. 在 Mac 的 图像捕捉（或 照片 App → 导入）中选择 iPhone。
  3. 选好保存的文件夹，点 全部下载。
  4. 在周末相册里用 上传收到的照片 放入这个文件夹。

提示 iPhone 设置 → 照片 →“传输到 Mac 或 PC”选 保留原片，就会以 HEIC 原样传过来（“自动”会转成 JPG）。实况照片会变成照片和视频两个文件。

iPhone · iCloud 照片 → Mac

  1. 如果 iCloud 照片开着 优化 iPhone 储存空间，手机里只有缩小的副本，原图在 iCloud 上。
  2. 在 Mac 的 系统设置 → Apple 账户 → iCloud → 照片 打开（同一个 Apple 账户），然后在 照片 App 里选好照片。
  3. 文件 → 导出 → 导出未修改的原件，导出到一个文件夹。
  4. 用 上传收到的照片 放入这个文件夹。

提示 Mac 空间不够的话，也可以在 iCloud.com → 照片 里挑选后下载。

安卓 → Mac

  1. 第一次：在“终端”里运行 brew install --cask android-platform-tools，并在手机的开发者选项里打开 USB 调试。
  2. 用数据线连接，在手机上点 允许 USB 调试。
  3. 在周末相册的 手机备份 标签页选好文件夹（相机、下载、微信等）然后搬移——新拍的照片会自动放进相册。
  4. 需要的话，只把核对过的文件 从手机删除。

提示 只要照片的话：把手机通知里的 USB 模式设为 传输照片（PTP），用 Mac 的图像捕捉导入也可以。

存在 Google 相册里的照片（iPhone、安卓通用）

  1. 点周末相册的 从 Google 相册导入照片。
  2. 在打开的 Google 相册窗口里选好要导入的照片。
  3. 只下载选中的照片，并按日期整理进相册。

提示 按照 Google 的政策，第三方应用只能接收用户亲手选的照片。数量很多的话，请用 Google 导出（Takeout）下载。

Windows PC

周末相册目前只有 Mac 版（Windows 版准备中）。在 Windows 上，请先把照片导入电脑。

iPhone → Windows 电脑

  1. 从 Microsoft Store 安装 Apple 设备 应用（iPhone 连接驱动）。
  2. 用数据线连接，在 iPhone 上点 信任。
  3. 用 Windows 的 照片 应用 → 导入 → 从连接的设备，或在文件资源管理器 → Apple iPhone → Internal Storage → DCIM 里复制。

提示 如果用 iCloud 照片，请用 适用于 Windows 的 iCloud 下载原图。HEIC 打不开的话，安装 Microsoft Store 里的“HEIF 图像扩展”，或把 iPhone 的传输设置改成“自动”（JPG）。

安卓 → Windows 电脑

  1. 用数据线连接，在手机通知的 USB 模式里选 文件传输（MTP）。
  2. 打开文件资源管理器 → 手机名称 → 内部存储。
  3. 把 DCIM/Camera（相机照片）、Pictures 里的微信（WeiXin）等聊天应用文件夹、Download（下载）复制到电脑。

提示 也可以用 Windows 照片 应用的导入、手机连接（Phone Link），三星手机还能用 Smart Switch。
