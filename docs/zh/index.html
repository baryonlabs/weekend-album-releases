不只是相册

照片越多，烦心事越多。分一点给我们。

相机存储卡、手机、移动硬盘、塞满的 Mac。不核对清楚，什么都不删；每一步都能撤销。

SD 卡备份

插上卡就行，什么时候能放心格式化，会告诉你。

插入相机或行车记录仪的 SD 卡，选好移动硬盘。卡里的文件夹原样复制过去，再从硬盘重新读一遍，确认和原件一模一样。全部对上了，就会显示：“✅ 这张卡可以清除了。”

  • 一张卡对应一个文件夹。下次插同一张卡，只补新增的文件
  • 卡上的隐藏文件夹和回收站也一并复制，一个不落
  • 多张卡排队备份：“推出并备份下一张卡”
手机备份

下载和聊天文件搬出手机，空间回来了

用数据线连上安卓手机，选好文件夹（下载、相机、微信的图片和媒体文件，还有 KakaoTalk 等），搬到移动硬盘。两边逐一比对后，愿意的话只删除已核对的文件。新照片会自动放进周末相册，原图留在硬盘上，几乎不占 Mac 空间。

  • 复制后又有变动的文件，绝不会被删
  • 手机上打开一次“USB 调试”就好
  • 用 iPhone？在 Mac 上用“图像捕捉”或“照片”通过数据线导入；只在 iCloud 里的原图，从“照片”App 导出 · 按手机和电脑分的导入方法 →
整理硬盘

移动硬盘乱成一团？先给你一份报告。

扫描硬盘后，在动任何文件之前，先让你看到重复文件、垃圾文件、空文件夹，以及每个文件夹占了多少空间。选好要留的，其余移进暂存文件夹；零散的照片和视频按年/月文件夹归好。

  • 只有每个字节都相同的文件才算重复
  • 每次整理都能一键撤销
  • SD 卡备份文件夹和 Time Machine 磁盘不会被碰
备份 · 释放空间

Mac 满了？相册还在，负担没了。

先把相册备份到移动硬盘，再点释放 Mac 空间。只有核对过的原图会从 Mac 上删除，预览照样留着；只要接上硬盘，原图和视频随时打开。个人文件夹里的大照片、视频文件夹，也可以挑出来搬到硬盘。

  • 删除前的最后一刻，再读一遍硬盘上的副本
  • 想要的时候随时“放回 Mac”
  • 照片图库、代码项目和相册文件夹从不搬动
  • 废纸篓没清空之前都能撤销
  • 也能备份到 Google 云端硬盘，顺便整理
操作记录

什么搬去了哪里？几个月后也答得上来。

每一次搬移和删除都记录到每一个文件。以后点一下重新确认结果，就能确认文件都还在硬盘上，记录本身也没被改动、没有缺页。

  • 每个文件的原位置、新位置、大小和 MD5
  • 记录之间用哈希串起来，改动或缺失一查便知
  • 记录只保存在你的 Mac 上
做相册

你只管挑照片

一个周末一本相册

周六周日的照片按周末分组（“8 月第 3 周”），工作日的照片按月归档（“9 月工作日”）。旅行和活动也能单独成册。

从哪儿来的都行

可以从 Google 相册里挑，也可以把朋友在微信里发来的照片直接拖进来。应用读取拍摄日期，把每张照片放到对的位置，连谁拍的都能记下来。

故事里有时间也有地点

地名、日期、时刻，春节、中秋这样的节日，连店招上的字都串成那天的行程；你请它写，Claude 就写成一篇日记。再改几笔，就是你自己的故事。

相册书和 PDF

挑几张最爱的，就是一本相册书。好几个周末合成一个 PDF，直接发到家庭群。

My Insta · Mac 本机 AI

在你 Mac 上运行的 AI（Apple Vision · Laya）几秒内挑出最佳照片、话题标签和合适的歌，照片不发往任何地方。歌曲来自韩语歌曲库，以 30 秒片段轻轻播放。

重复更少，空间更多

聊天里收到两次的同一张照片，找出来把副本移到废纸篓；已备份的原图也整理一下，给 Mac 腾出空间。

安装

三步搞定

这个应用不是从 App Store 下载的，所以 Mac 会请你确认一次，只在第一次。

🍎 Mac

  1. 下载并打开 DMG

    点上面的下载 Mac 版，再双击下载好的文件。

  2. 拖进“应用程序”

    在打开的窗口里，把周末相册的图标（名字显示为“주말 사진첩”）拖到旁边的“应用程序”文件夹。

  3. 第一次打开，点“仍要打开”

    如果 macOS 提示无法验证应用或开发者，打开系统设置 → 隐私与安全性，滚到最下面，点仍要打开。 如果提示应用“已损坏，无法打开”，把下面这行粘贴到“终端”里运行，再打开应用。

    xattr -dr com.apple.quarantine "/Applications/주말 사진첩.app"

🪟 Windows 10/11

  1. 运行安装程序

    双击上方 下载 Windows 版 得到的 WeekendAlbum-1.15.1-Setup.exe。不需要管理员权限，只安装到你的账户。

  2. 第一次：“更多信息 → 仍要运行”

    若出现 Windows 已保护你的电脑，点 更多信息，再点 仍要运行。这是尚无代码签名证书的新应用，只会出现第一次。 若 Windows 11 提示“应用程序控制策略已阻止此文件”（智能应用控制），目前无法运行 — 请使用即将推出的 Microsoft Store 版本。

  3. 打开应用并选择视图

    从开始菜单（或桌面）打开 周末相册，选择 家庭 或 专业。照片会集中到 图片\주말 사진첩。Windows 10 若窗口一片空白，请安装 Microsoft Edge WebView2 运行时 后重新打开。

  4. （可选）视频与安卓手机工具

    要使用视频场景/片段和手机备份，请把下面几行粘贴到 PowerShell 安装免费工具。按人脸归类、照片内容 AI 分类和“照片”应用同步仅限 Mac。

    winget install Gyan.FFmpeg
    winget install Google.PlatformTools

照片与隐私

你的相册，住在你的 Mac 上

不经过我们的服务器

相册建在你 Mac 的“图片”文件夹里。Baryon Labs 从不接收你的照片、故事或笔记。只有你自己选择时，照片才会离开 Mac，比如备份到你自己的 Google 云端硬盘。

大部分在 Mac 上完成

选图、话题标签和配歌由你 Mac 上的 AI 处理。只有在你请它写的时候，几张选中的照片和“何时何地”的摘要（精确到街道一级）才会发送到你自己的 Claude 账户。原图、文件名和 GPS 坐标不会发送。

每一步都有记录

每个被搬移或删除的文件，其位置、大小和 MD5 只保存在这台 Mac 上，以后随时能核对是否完好。

只有匿名使用次数

Baryon Labs 只收到哪些功能被用了、用了几次的匿名统计。具体会发送什么、以及如何关闭，都在应用的“ⓘ 信息”里看得到。

详情见应用内“ⓘ 信息”→ 数据与 AI 说明、使用条款和隐私政策。周末相册可免费用于个人、家庭以及工作。
